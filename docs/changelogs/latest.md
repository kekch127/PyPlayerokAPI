# 1.1.3
- Выполнен рефакторинг кода
- Добавлена типизация
- Добавлены комментарии к коду
- Исправлены логические ошибки

- Основные нововведения
    - Добавлена полностью асинхронная система обработки ивентов
    - Добавлен `EventFactory`, отвечающий за генерацию ивентов из сообщений чата.
	    - Основные возможности: 
            - Построение `PlayerokEvent`
            - Обработка системных маркеров
            - Динамическое подключение кастомных маркеров
            - Защита от повторной обработки сделок
            - TTL очистка обработанных сделок
    - Каждый подключенный `watcher` можно отключить вручную `(account._deal_watcher.stop())`
    - Добавлены тесты `pytest`. Для запуска:
        - Установите библиотеку: `pip install pytest pytest-asyncio`
        - Запустите тесты: `pytest -v`
- Изменения
	- Полностью переработана архитектура `listener` системы
    - Переработана система потока ивентов. Теперь поток ивентов выглядит так: `WebsocketClient -> *Watchers -> *queue_forwarding -> Dispatcher -> Handlers`
	- Добавлена защита от утечек памяти. EventFactory использует TTL очистку обработанных сделок
    - Добавлен унифицированный механизм статуса сделки. Каждый маркер имеет в конфигурации параметр `include_status_change` который автоматически добавляет и возвращает `PlayerokEvent` с маркером `DEAL_STATUS_CHANGED`
- Исправлено
    - Исправлена "дорогая операция" при вызове `inspect` во время расчета типа вызова хендлера. Расчет типа производится при первом вызове хендлера и сохраняется
	- Исправлены возможные дубликаты ивентов сделок
	- Исправлена повторная обработка маркеров
	- Исправлена возможная утечка памяти `processed_deals` 
	- улучшена устойчивость `websocket reconnect`
	- улучшена обработка ошибок API
    - Исправлены конфигруации моделей: переход в `class Config` (Pydantic v1) на `ConfigDict` (Pydantic V2)
    - Исправлены некоторые модели
    - Исправлены Persisted queries
- Миграция
	- Старые синхронные обработчики `listener` больше не используются. Теперь обработчики должны быть `async`
	- Получение ивентов вручную так-же теперь должны быть `async` итераторами или используйте метод `await listener.get()`
    - Изменены назвния файлов и классов
        - Файлы
            - `async_dispatcher.py -> dispatcher.py`
            - `async_router.py - router.py`
            - `markers.py -> markers/ -> base.py, registry.py`
        - Классы
            - `AsyncEventDispatcher -> EventDispatcher`
            - `AsyncPlayerokRouter -> PlayerokRouter`
            - `WebSocketClient -> WebsocketClient`
            - `AsyncPlayerokListener -> PlayerokAccountListener`
            - `AsyncMultiAccountListener -> PlayerokMultiAccountListener`
